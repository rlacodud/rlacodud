# **안녕하세요, 기획 의도를 구조로 만들고 막힌 문제는 원인까지 파고드는 프론트엔드 개발자 김채영입니다.**

#### 디자인 시안이나 화면 설계 없이 시작하는 프로젝트에서도, 기획 의도를 실제 서비스 구조와 기능으로 구체화하는 데 강점이 있습니다. 화면을 구현하는 데서 끝내지 않고 이 기능이 정말 필요한지까지 고민하는 게 제가 일하는 방식입니다.

#### 개발은 혼자보다 함께 풀 때 더 재미있다고 생각합니다. PR 템플릿과 회고 문화를 직접 제안해 팀이 지식을 나누는 환경을 만들었고, 기술 블로그에 100편 넘는 글을 남기며 배운 것을 기록하고 공유해왔습니다.

#### 답이 바로 보이지 않는 문제도 하나씩 분석해서 끝까지 원인을 찾아갑니다. 외부 라이브러리 없이 3주 만에 만든 Canvas 미니게임이 저사양 기기에서 멈추는 문제를, 렌더링 구조를 직접 뜯어보고 개선해 해결한 경험이 있습니다.
